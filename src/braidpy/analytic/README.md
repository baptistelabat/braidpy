# braidpy.analytic

This directory is named for a thing that turned out not to exist: a closed-form
map from a braid word to the shape the strands take when the braid is pulled
tight. It holds no code, and only this pointer.

The argument for why that map does not exist, and the symmetric special cases
where something closed-form does survive, is in the documentation:

- `docs/source/why_no_closed_form.md` — why there is no formula, where closed
  form does survive, and what is in the package instead.
- `docs/source/solving_numerically.md` — the numerical problem worth posing
  once the analytic one is abandoned. Not implemented.

Keeping the directory seemed better than pretending the question was never
asked.
